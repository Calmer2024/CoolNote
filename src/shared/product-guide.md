# 欢迎使用 CoolNote

CoolNote 是一款本地优先的个人知识与创作资料库，用一个工作区统一管理笔记、小记、任务和画廊。内容默认保存在本机，编辑过程自动保存；切换内容或关闭窗口前，应用会尽力提交仍在等待保存的修改。

## 先认识界面

- 最左侧是全局导航：全部笔记、收藏、归档、回收站、小记、任务和画廊都从这里进入。
- 顶部搜索框会同时搜索笔记、小记、任务和画廊；输入关键词后可直接打开结果。
- 第二栏显示当前模块的列表或资源树；可以通过工具栏按钮或 Ctrl+B 折叠与展开。
- 主内容区用于阅读和编辑；笔记右侧还带有文档大纲，可用 Ctrl+/ 折叠与展开。
- 右上角主题按钮可以在浅色、深色和跟随系统之间切换。
- 加载数据时，侧边栏和内容区会先显示带微光动画的骨架占位，数据到达后平滑切换为真实内容。

## 笔记与分类

- 在分类标题旁点击加号，新分类会直接出现在列表末尾；填写名称后按 Enter 或点击外部完成创建，按 Escape 取消。
- 新建分类时点击图标可打开图标与颜色卡片；已存在的分类可双击图标再次修改外观。
- 点击分类右侧的新建入口，可以在该分类中新建空白笔记，或导入 Markdown、HTML、JSON 和纯文本内容。
- 笔记列表支持按更新时间升序或降序排列，并会在滚动到底部时继续载入更多内容。
- 鼠标悬停在笔记条目上可收藏或打开更多菜单；更多菜单支持移动分类、归档和移到回收站。
- 勾选多个笔记后可以批量收藏、取消收藏、移动、归档、恢复或删除。
- 回收站中的笔记可以恢复或永久删除，也可以使用标题栏按钮清空回收站；永久删除无法撤销。
- “欢迎使用 CoolNote”是置顶的内置产品介绍，不能移动、归档或删除，但会随版本更新补充说明。

## 笔记编辑器

- 点击标题即可重命名；标题下方可以选择心情，右下角会实时显示正文字符数。
- 正文支持一至五级标题、正文、粗体、斜体、下划线、删除线、行内代码、链接、高亮、引用、无序列表、有序列表和可勾选任务列表。
- 选中文字后会出现浮动格式工具栏，可直接切换标题级别、粗体、斜体、下划线、删除线、行内代码和链接。
- 在空段落开头输入 / 会打开内容块菜单；继续输入名称或拼音可筛选，使用上下方向键移动，Enter 插入，Escape 关闭。
- 斜杠菜单可插入正文、各级标题、列表、任务列表、引用、代码块、图片或附件、网页资源、表格、数学公式和 Mermaid 图。
- 常用 Markdown 输入会自动转成样式，例如双星号包裹的粗体、单美元符号包裹的行内公式和双美元符号包裹的块级公式；粘贴、中文输入法提交以及末尾没有空格时也会正常识别。
- 大段内容粘贴会分批处理并显示进度；可以取消并恢复到粘贴前状态，避免界面长时间卡住。

## 图片、附件与网页资源

- 图片可以通过文件选择器插入，也可以直接粘贴或拖入正文；连续插入的图片会自动形成并排布局。
- 点击图片可以选中，拖动图片可调整顺序，拖动右下角手柄可改变单图宽度；选中后按 Backspace 或 Delete 删除。
- 附件支持图片、音频、视频、PDF、压缩包、文本、Markdown、HTML 等常见文件。
- 音频和视频可在笔记内直接播放；网页链接与本地 HTML 会在沙箱 iframe 中内嵌预览。
- 附件卡片提供打开资源、在资源管理器中显示和另存为操作；网页资源可一键跳转到原地址。
- 多个相同附件会复用本地资源内容，笔记中仍保留各自的引用关系。

## 表格、代码、公式与图表

- 插入表格默认创建带表头的 3×3 表格；光标进入单元格后，可从浮动工具栏在上下插入行、左右插入列，或删除当前行、当前列和整张表格。
- 代码块支持多种语言语法高亮；点击代码块后可搜索或选择语言，方向键选择，Enter 确认，Escape 收起候选列表。
- 行内公式使用一对美元符号包裹，块级公式使用两对美元符号包裹；也可以从斜杠菜单打开 LaTeX 输入框后插入。
- Mermaid 图支持流程图、时序图和结构图等语法；在输入卡片中按 Ctrl+Enter 确认，按 Escape 取消。

## 查找、保存、分享与导出

- 笔记正文内按 Ctrl+F 打开查找，按 Ctrl+H 打开查找与替换。
- 查找框中按 Enter 前往下一个结果，按 Shift+Enter 返回上一个结果，按 Escape 关闭。
- 编辑内容会自动保存；工具栏会显示保存中、已保存或失败状态。异常退出后再次启动时，CoolNote 会提示恢复安全草稿或保留数据库版本。
- 文档工具栏的“分享”会复制或调用系统分享能力；更多菜单可以导出 Markdown 或 PDF。
- 导入和导出会尽量保留标题、段落、列表、表格、代码、公式以及其他受支持的内容块。

## 小记

- 小记适合轻量写作、灵感记录和可分享的长内容；第二栏以文件夹和小记组成资源树。
- 点击加号可新建文件夹或小记；名称输入完成后按 Enter 或点击外部确认，按 Escape 取消。
- 小记可拖入文件夹，也可拖回根目录；双击名称或使用悬停操作可以重命名。
- 小记正文支持标题、正文、粗体、斜体、下划线、删除线、链接和图片；选中文字后会出现与笔记一致的快捷格式菜单。
- 图片支持选择、粘贴和拖拽插入。
- 封面支持 24 张内置图片和本地上传；“内置图片 / 上传”按钮仅在封面悬停或聚焦时显示。
- 更多菜单可以插入图片，并将小记导出为 Markdown、PDF 或长图。

## 任务

- 任务模块包含收集箱、全部任务、今天、已完成、自定义清单和日历视图。
- 点击“新建任务”后直接在下方输入名称，按 Enter 或点击外部创建，按 Escape 取消；不需要额外点击确认按钮。
- 点击任务左侧圆形完成按钮会播放完成动画，短暂保留完成状态后再从当前清单移入“已完成”。
- 点击任务条目可展开或收起详情与子任务；再次点击已展开条目会关闭详情，点击详情栏外部也会关闭。
- 任务可设置备注、开始时间、结束时间、重要程度和所属清单；未设置日期时显示空状态，日期与重要程度使用浅色胶囊展示。
- 重要程度分为紧急、重要、普通和较低，并用不同颜色的圆形图标区分。
- 表格标题、日期、重要程度和所属清单都带有对应图标；拖动列与列之间的边界线可以调整列宽。
- 筛选器支持状态、重要程度和日期条件，排序支持自定义、开始时间、结束时间和重要程度。
- 自定义清单可在侧边栏末尾原地创建、改名、选择图标和填写备注；清单本身支持拖拽排序。
- 日历视图显示完整六周网格；点击日期可快速创建当天任务，点击日历中的任务可打开详情。

## 画廊

- 画廊用于集中收藏和整理图片；每个画廊都有名称、介绍、封面和可手动调整的顺序。
- 新建画廊后在第二栏原地输入名称；画廊可重命名、拖拽排序或删除。
- 封面支持 24 张内置图片和本地上传；封面操作在悬停或聚焦时显示。
- 可以点击导入按钮选择多张图片，也可以把图片直接拖入画廊；导入进度会显示新增、跳过和失败数量，并可中途取消。
- 相同图片会按内容去重，避免重复占用空间；同一图片仍可出现在多个画廊中。
- 画廊图片支持拖拽排序、批量选择、移动或复制到其他画廊、下载和删除。
- 点击图片进入灯箱；使用左右方向键切换，按 Escape 退出，也可以复制或下载当前原图。

## 快捷键速查

- Ctrl+K：聚焦全局搜索。
- Ctrl+B：折叠或展开当前模块的第二栏。
- Ctrl+N：在笔记或小记模块中新建内容。
- Ctrl+/：折叠或展开笔记大纲。
- Ctrl+1 至 Ctrl+5：把当前段落设为对应级别的标题；Ctrl+6 恢复为正文。
- Ctrl+I：切换斜体。
- Ctrl+U：切换下划线。
- Ctrl+T：插入 3×3 表格。
- Ctrl+F：查找正文。
- Ctrl+H：查找并替换。
- Enter / Shift+Enter：查找下一个 / 上一个结果。
- Ctrl+Enter：确认 Mermaid 源码输入。
- 方向键、Enter、Escape：用于斜杠菜单、代码语言菜单和多数弹出卡片的选择、确认与关闭。
- 灯箱中的 ← / → / Escape：上一张、下一张、退出灯箱。

## 数据与安全

- CoolNote 默认离线工作，核心数据保存在本机 SQLite 笔记库，附件和画廊原图保存在本地资源目录。
- 删除分类时，其中的普通笔记会移到“我的文件”；内置产品介绍始终受到保护。
- 重要删除操作会要求再次确认；部分可恢复操作会提供撤销提示。
- 建议定期备份整个 CoolNote library 文件夹，这样可以同时保留数据库、附件和画廊资源。

如果暂时不确定从哪里开始，可以先在“我的文件”中新建一篇笔记，输入 / 浏览所有内容块，再到任务和画廊中分别创建一个清单与一个画廊。CoolNote 会在你使用过程中持续自动保存。
