# 代码复制与文本绘图 UX 验收

## 实现

- 笔记、小记的代码块复用同一个 NodeView，复制按钮位于右下角，使用应用现有的复制图标，无可见文字、边框或背景。代码底部预留空间，不覆盖正文。
- 剪贴板使用代码节点的 textContent，保留换行、缩进、Tab、特殊字符及末尾空行，不包含高亮标签、行号、按钮或 Markdown 围栏。复制成功后显示主题蓝色对勾两秒，失败显示错误图标并可重试；无障碍标签保留相应状态。反馈仅属于视图，不写入笔记。
- 文本绘图源码与普通代码块共用 --font-code、字号、行高和 Tab 宽度。
- 图表渲染前读取编辑器正文的实际 font-family，沿用同一中英文字体栈及回退顺序，并等待字体加载后计算布局。监听祖先的字体/主题属性及字体加载完成事件，重新渲染；销毁后清理监听。
- 图表容器和 SVG 画布背景透明，保留外框。图内节点仍使用 Mermaid 主题的配色以保证文字可读。

## 验证

- 自动测试覆盖代码完整复制、特殊字符、末尾空行、空代码块、选区/文档不变、编辑后复制最新内容、失败重试，以及字体/主题更新、字体加载等待、销毁清理。
- npm run build 全部通过，包含编辑器、任务、小记相关测试、契约检查、TypeScript 和生产构建；新增字体加载测试也已单独通过。
- 使用加载真实组件和样式的临时浏览器预览检查浅色/深色及两组中英文字体。实际点击复制后粘贴到输入框，确认换行、Tab 和特殊字符原样保留。
- 浏览器计算样式确认源码和普通代码的字体栈一致，图表字体和正文一致；容器/SVG 背景均为透明。初版复制按钮位于标题栏，后按反馈移至代码块右下角的预留底部区域，互不重叠。示例中英文标签未见裁切或重叠。
- 临时预览已移除，不向用户笔记写入验收内容。浏览器检查不能完全替代桌面 WebView 的人工验收。

## 桌面验收步骤

1. 在笔记和小记中分别插入代码块，输入多行代码（含空行、Tab、中文、反引号及 <>& 字符），点击复制，粘贴到纯文本编辑器逐字对比。
2. 复制前选择部分代码，确认点击复制后选择不被修改，且复制的是整个代码块。编辑代码后再次复制，检查为最新内容。
3. 检查按钮反馈、键盘 Tab 聚焦及 Enter/空格触发，在窄窗口和长代码块内选择/滚动，确认按钮不覆盖代码。
4. 插入包含中文和英文的 Mermaid 流程图/时序图，对比源码与普通代码字体，对比图中文字与正文中英文字体。
5. 切换设置中的字体和浅色/深色主题，检查图表自动刷新、背景透明、文字清晰，无明显裁切或重叠；多个图表及无效语法的局部错误仍相互独立。
