# CoolNote 静态 UI 复现设计规格

## 目标

参考用户提供的 NoteFlow 桌面笔记产品截图，制作一个可直接在浏览器中打开的 CoolNote 静态 HTML 页面。页面用于确认桌面端产品的布局、视觉层级和内容密度，不实现任何实际业务功能。

## 复现范围

只复现截图中的笔记应用界面，排除截图来源平台叠加的头像、点赞、收藏、评论、分享、字幕、底部推荐及其他视频播放控件。

页面包含：

- 顶部全局工具栏
- 左侧应用导航栏
- 中间笔记列表
- 主笔记正文区域
- 右侧文章大纲

## 技术方案

- 使用原生 HTML5 和独立 CSS 文件。
- 使用 CSS Grid 构建整体多栏布局，使用 Flexbox 完成栏内排列。
- 图标使用 HTML 中的内联 SVG，不加载 CDN、网络字体或第三方图标库。
- 品牌 Logo 作为本地 `assets/logo.svg` 文件提供。
- 不使用 JavaScript、前端框架、包管理器、构建工具或第三方依赖。
- `index.html` 可通过文件协议直接打开，也可由任意静态 HTTP 服务器托管。

预期文件结构：

```text
CoolNote/
├── index.html
├── styles.css
└── assets/
    └── logo.svg
```

## 页面布局

### 顶部工具栏

- 固定在页面顶部，高度约 `72px`。
- 左侧放置搜索框，包含搜索图标、占位文字“搜索笔记…”和快捷键提示。
- 搜索区域右侧依次放置主题图标和蓝色“新建”按钮。
- 使用浅色底部边线与主体区域分隔。

### 主体多栏布局

在宽屏桌面尺寸下，主体区域分为以下栏目：

1. 左侧导航栏：基准宽度约 `280px`。
2. 笔记列表：基准宽度约 `390px`。
3. 主内容区：占据剩余可用宽度。

主内容区内部继续划分为正文和右侧大纲，大纲基准宽度约 `230px`。各栏目使用细浅灰分隔线，不使用明显阴影或卡片边框。

页面铺满浏览器窗口高度。左侧导航、笔记列表、正文和大纲均允许独立纵向滚动，滚动条保持细且低对比度。

### 响应式规则

- `1920×1080` 是主要视觉验收尺寸。
- 同时检查 `1440×900` 和 `1280×720`。
- 当窗口宽度低于约 `1280px` 时隐藏右侧大纲，为正文释放空间。
- 当窗口宽度低于约 `980px` 时压缩左侧导航和笔记列表宽度，但保持三栏结构和正文基本可读性。
- 本阶段不设计移动端布局。

## 内容设计

### 品牌与导航

- 应用品牌名称使用 `CoolNote`。
- 使用蓝色圆角方形 Logo。
- 主导航包含：全部笔记、日程、收藏、画板、回收站。
- 分类导航包含：八股、学习小记、面经、项目、算法题。
- 分类右侧展示静态笔记数量。

### 笔记列表

- 列表顶部显示“全部笔记”和笔记总数。
- 提供多条具有标题、摘要、日期和分类标签的静态笔记。
- 示例笔记包括：RocketMQ、MiraAgent、仿美团神券系统、Redis、MySQL。
- `MiraAgent` 显示为当前选中笔记。
- 选中状态使用左侧蓝色竖线，并通过轻微背景或文字层级加强识别。
- 分类标签使用浅蓝背景和蓝色文字。

### 正文区域

- 顶部展示 `MiraAgent` 大标题、项目标签和“添加标签”提示。
- 正文工具栏包含保存状态、置顶、收藏、阅读、分栏、编辑和更多操作。
- 正文内容包含项目简介、技术栈、主要工作要点以及“介绍一下这个项目”等章节。
- 正文宽度、字号和行高应形成接近真实笔记的阅读密度，避免大面积无意义占位。

### 右侧大纲

- 顶部显示“大纲”。
- 目录条目来源于正文中的静态标题和小节。
- 当前或主要章节使用更深的文字色或蓝色强调。
- 大纲区域与正文之间使用浅灰竖线分隔。

## 视觉规范

- 整体采用白色和极浅灰色背景。
- 主文字使用接近黑色的深灰；辅助文字使用中性灰。
- 品牌色和选中强调色采用清晰但不过度饱和的蓝色。
- 使用 Windows 中文显示友好的系统字体栈，不依赖网络字体。
- 标题、正文、辅助文字和标签形成明确的字号、字重及颜色层级。
- 页面保持宽松留白，不增加渐变、玻璃拟态、重阴影或装饰性纹理。
- 不复制原截图因视频压缩产生的模糊，文字和图标应保持清晰。
- 静态按钮允许有 CSS 悬停反馈，但不执行操作。

## 明确不实现的内容

- 搜索和快捷键
- 新建笔记
- 编辑或保存正文
- 笔记及分类切换
- 主题切换
- 收藏、置顶、阅读、分栏等工具操作
- 拖拽调整栏目宽度
- 数据加载、持久化或同步
- 登录、云服务或桌面端封装
- 移动端适配

## 验收标准

1. `index.html` 可以直接打开，且不依赖网络资源。
2. 在 `1920×1080` 下完整呈现顶部栏、导航栏、笔记列表、正文和大纲。
3. 页面栏目比例、间距、分隔线、字体层级、颜色和内容密度与参考截图高度相似。
4. 视频平台叠加元素不会出现在页面中。
5. 在 `1440×900` 下布局仍然完整可读。
6. 在 `1280×720` 左右按规则隐藏大纲，正文不会被横向遮挡。
7. 页面不包含 JavaScript，也不会发起外部网络请求。
8. HTML 和 CSS 结构清晰，后续可以把导航、笔记列表、编辑区和大纲迁移为独立桌面端组件。

## 后续阶段

静态页面经过视觉评审并确认后，再单独设计桌面端技术架构、编辑器方案、数据模型、本地存储、搜索、同步及其他实际功能。本规格不预先确定桌面端框架。
