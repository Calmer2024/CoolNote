# 大纲折叠按钮图标与位置稳定设计

日期：2026-08-11

## 目标

大纲折叠后继续使用展开状态下的 `list-tree` Lucide 图标，并保持按钮在大纲区域中的原有位置，不因折叠状态切换到顶部或居中位置。

## 设计

- `index.html` 中大纲按钮的 `data-expanded-icon` 与 `data-collapsed-icon` 均设为 `list-tree`。
- 大纲展开时保持现有标题按钮样式。
- 大纲折叠时仅隐藏“大纲”文字和目录内容。
- 折叠态大纲仍为 42px 宽，但沿用展开态的顶部间距和水平起点；不再使用 `align-items: flex-start`、`justify-content: center` 或折叠态专用的顶部 18px 定位。
- 图标按钮仍可点击并正确同步 `aria-expanded` 和 `aria-label`。
- 不修改笔记栏、最侧边栏、正文、字体或其他视觉样式。

## 验收

- 展开与折叠状态下 `<use>` 均引用 `assets/lucide-icons.svg#list-tree`。
- 折叠前后按钮的顶部坐标和左侧坐标保持一致，允许不超过 1px 的渲染误差。
- 折叠后大纲目录与“大纲”文字隐藏，大纲宽度仍为 42px。
- 点击图标可反复收起和展开大纲。
- 静态校验和浏览器控制台检查通过。
