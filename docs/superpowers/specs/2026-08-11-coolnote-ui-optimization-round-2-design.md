# CoolNote UI 第二轮优化设计

日期：2026-08-11

## 目标

在不增加业务功能的前提下，继续贴近参考截图优化 CoolNote 静态页面：简化折叠入口，使文档工具栏、大纲与正文成为连续的工作区；压缩笔记列表密度；统一标签视觉；并内置适合中文界面的字体。

## 范围

本轮只修改现有静态 HTML、CSS、面板折叠脚本和静态校验。不会增加笔记编辑、数据持久化、导航、搜索或桌面端能力。

## 实现路线

采用基于现有结构的精确调整方案。保留当前 HTML、CSS 和原生 JavaScript 组织方式，只删除无效折叠状态、合并重复入口并调整网格和视觉样式。本轮不引入组件框架，也不使用纯 CSS 状态替代现有脚本。

## 布局与组件

### 最侧边栏

- 最左侧导航栏永久显示且宽度保持不变。
- 删除该栏的折叠按钮。
- 删除 HTML 上的侧栏折叠状态、CSS 折叠选择器以及 JavaScript 中对应的状态管理。
- 已确认的导航图标、蓝色分类图标与视觉样式保持不变。

### 笔记列表栏

- 删除笔记列表标题区域中的折叠按钮。
- 仅保留文档顶部工具栏中的笔记栏折叠按钮。
- 展开状态下，笔记栏保持现有布局位置。
- 收起状态下，笔记栏宽度变为零且内容完全隐藏，不保留窄栏或占位按钮。
- 工具栏按钮始终可见，用于再次展开笔记栏。
- 笔记列表项的整体纵向尺寸缩小约 15% 至 20%，包括上下内边距、标题与摘要间距、元信息顶部间距；信息层级、文本内容和已确认的激活态设计不变。

### 文档工具栏与元信息

- 移除文档顶部工具栏与下方内容之间的横向分隔线。
- 工具栏继续横跨大纲和正文上方。
- 文档标题附近的“项目”和“标签”继续使用底部圆角矩形造型，但取消边框。
- 项目使用极浅蓝色纯填充和蓝色文字；标签使用极浅灰蓝色纯填充和柔和灰蓝色文字。
- 填充颜色比当前版本更浅，以降低视觉重量。

### 大纲与正文

- 移除大纲与正文之间的竖向分隔线，以留白区分两块内容。
- 将“大纲”文字左侧现有的 Lucide 图标改为大纲折叠控制按钮。
- 删除大纲区域内原有的独立折叠按钮。
- 大纲展开时，图标按钮位于标题文字左侧；点击后收起大纲。
- 大纲收起后，仅在文档内容区左侧保留一个固定的 Lucide 展开按钮，不保留标题、目录内容或空白栏。
- 大纲状态改变时，正文自动占据释放出的宽度。

## 图标约束

- 所有界面图标继续从本地 Lucide 图标库 `assets/lucide-icons.svg` 引用。
- 禁止使用 Unicode 符号、Emoji、字符箭头、自绘 CSS 图形或其他非图标库方案充当图标。
- 折叠按钮应通过图标方向和可访问名称表达当前操作。

## 字体

- 下载并随项目内置 Noto Sans Simplified Chinese 的 WOFF2 文件，以确保桌面端和离线环境可用。
- 使用 `@font-face` 注册本地字体，并将其设为页面首选字体。
- 拉丁字符也优先使用该字体；系统无衬线字体作为加载失败时的后备。
- 页面运行时不依赖 Google Fonts CDN。

## 状态管理

- 折叠脚本只管理 `notes` 和 `outline` 两种状态。
- 删除 `sidebar` 状态及其按钮映射。
- 每个面板只保留一个有效控制入口：文档工具栏控制笔记栏，大纲标题图标控制大纲。
- 按钮同步维护 `aria-expanded`、可访问名称以及对应的根节点状态属性。
- 本轮脚本不承担折叠之外的业务功能。

## 响应式与异常处理

- 页面仍以桌面端布局为目标。
- 在较窄桌面窗口中，已收起的笔记栏或大纲不得留下不可见占位宽度。
- 字体文件加载失败时自动回退到系统无衬线字体，不影响内容展示。
- 图标精灵加载失败不使用 Unicode 或 Emoji 替代，以避免违反图标约束。

## 验收与测试

### 自动静态检查

- 最侧边栏不存在折叠按钮、折叠属性或脚本状态。
- 笔记列表标题区域不存在折叠按钮，文档工具栏中存在唯一笔记栏按钮。
- 大纲不存在独立尾部折叠按钮，标题左侧图标是唯一大纲控制入口。
- 笔记栏收起宽度为零，大纲收起后仅保留固定展开按钮。
- 工具栏底部分隔线和大纲右侧分隔线已移除。
- 项目与标签无边框，并使用浅色纯填充。
- 页面已声明并引用本地 Noto Sans Simplified Chinese WOFF2。
- 页面中不存在 Unicode 或 Emoji 图标。

### 交互检查

- 文档工具栏按钮可反复收起和展开笔记栏。
- 笔记栏收起后完全不可见，且按钮仍可操作。
- 大纲标题图标可收起大纲；固定图标按钮可再次展开。
- 两个折叠状态可独立组合，不互相覆盖。
- 所有折叠按钮的 `aria-expanded` 与实际状态一致。

### 视觉检查

- 在 1920×1080、1440×900 和 1280×720 三种视口下检查展开、单栏收起和双栏收起状态。
- 确认顶部工具栏、大纲和正文形成无分隔线的连续工作区。
- 确认笔记列表更紧凑但标题、摘要和元信息仍清晰可读。
- 确认项目与标签的填充色足够浅，并保持参考图中的底部圆角矩形感觉。
- 确认中文界面实际使用内置 Noto Sans Simplified Chinese。

## 非目标

- 不实现笔记内容编辑。
- 不实现项目、标签或笔记切换。
- 不实现搜索、同步、持久化或桌面端封装。
- 不重构为前端框架或通用面板组件。
