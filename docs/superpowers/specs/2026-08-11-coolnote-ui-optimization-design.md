# CoolNote 静态 UI 优化设计规格

## 目标

在现有 CoolNote 静态页面基础上，进一步贴近参考截图的布局和视觉表现，并加入仅用于 UI 评审的栏目折叠交互。

本规格覆盖以下优化：

1. 左侧导航、笔记列表和大纲均可折叠。
2. 分类图标统一为参考图中的蓝色线性风格。
3. 所有界面图标统一来自 Lucide Icons，不使用 Unicode、Emoji、自绘图标或 CSS 图标。
4. 重新设计笔记激活态。
5. 将大纲融入文档区域，并让文档顶部工具栏横跨正文和大纲。
6. 将文档标题下的项目和标签改为底部圆角矩形背景。

## 技术方案

保留原生 HTML 和 CSS 架构，新增一个小型原生 JavaScript 文件用于栏目折叠。

```text
CoolNote/
├── index.html
├── styles.css
├── app.js
└── assets/
    ├── logo.svg
    └── lucide-icons.svg
```

- `index.html`：页面语义结构、折叠按钮和 Lucide Sprite 引用。
- `styles.css`：展开、折叠、激活态、大纲和标签的全部视觉样式。
- `app.js`：仅管理栏目折叠状态和无障碍属性。
- `assets/lucide-icons.svg`：只包含页面实际使用的 Lucide 图标符号。

## 图标规范

- 删除现有 HTML 中全部自绘 `<symbol>`。
- 所有界面图标通过 `<svg><use href="assets/lucide-icons.svg#图标名称"></use></svg>` 引用。
- Logo 继续使用独立的品牌资源 `assets/logo.svg`，不作为界面操作图标处理。
- 不允许使用 Unicode 符号、Emoji、字符箭头或特殊字符模拟图标。
- 不允许使用 CSS 边框或伪元素绘制箭头、加号、菜单等界面图标。
- 分类图标统一使用品牌蓝色；普通导航与工具栏图标使用中性灰色，激活状态使用蓝色。

计划使用的 Lucide 图标包括：

- 搜索、太阳、新建、文件、日历、收藏、画板、回收站
- 书本、毕业帽、文件夹、标签、排序
- 左右栏展开/收起、置顶、阅读、分栏、编辑、更多
- 大纲列表和折叠控制

## 整体布局

页面继续使用顶栏加工作区结构。工作区的主要布局区域为：

1. 左侧导航栏
2. 笔记列表
3. 文档与大纲共同区域

文档与大纲共同区域改为：

```text
文档与大纲共同区域
├── 统一顶部工具栏
│   ├── 左侧栏目控制
│   └── 保存、置顶、收藏、阅读、分栏、编辑、更多
└── 阅读区域
    ├── 正文
    └── 融入式大纲
```

统一顶部工具栏跨越正文和大纲的完整宽度。阅读区域内部再使用 Grid 划分正文和大纲。

## 栏目折叠

### 左侧导航

- 展开时维持现有桌面宽度。
- 折叠后缩为约 `48px` 的窄栏。
- 窄栏只保留一个来自 Lucide 的展开按钮。
- 品牌、导航文字、分类和数量全部隐藏。

### 笔记列表

- 展开时维持现有列表宽度。
- 折叠后缩为约 `48px` 的窄栏。
- 窄栏只保留一个展开按钮。
- 标题、列表内容和排序按钮隐藏。

### 大纲

- 展开时作为阅读区域的右侧子区域。
- 不使用独立卡片、独立背景或与正文分离的顶部空间。
- 仅通过浅灰竖向分隔线体现层级。
- 折叠后保留约 `42px` 的右侧控制条和展开按钮。
- 较窄窗口自动隐藏大纲时，不显示该控制条。

### 状态和动画

- 根工作区通过 `data-sidebar-collapsed` 和 `data-notes-collapsed` 表示左侧栏目状态。
- 阅读区域通过 `data-outline-collapsed` 表示大纲状态。
- 宽度、透明度和可见性使用短促的 CSS 过渡，持续时间约 `160–200ms`。
- 折叠状态只存在于当前页面内，不写入 LocalStorage，刷新后恢复默认展开。
- 折叠按钮同步更新 `aria-expanded` 和 `aria-label`。

## 原生 JavaScript 边界

`app.js` 只允许：

- 查找带有 `data-collapse-target` 的按钮。
- 切换对应容器的折叠属性。
- 更新按钮的无障碍属性。
- 根据折叠状态切换 Lucide 图标引用。

`app.js` 不实现：

- 搜索或快捷键
- 新建、编辑和保存
- 笔记或分类切换
- 主题切换
- 数据加载、存储和同步
- 路由或桌面端接口

## 笔记激活态

`MiraAgent` 继续作为当前激活笔记，并按照参考图调整：

- 左侧显示清晰的品牌蓝色圆角竖线。
- 竖线与内容之间保留合理间距，不紧贴文本。
- 标题使用更深颜色和较高字重。
- 摘要保持中性灰色。
- 日期和分类标签位于底部同一行。
- 整体背景保持白色，只允许极轻的浅蓝渐变或局部强调。
- 激活项上下留白大于普通列表项，使其形成独立视觉分组。

## 融入式大纲

- 大纲位于 `.reading-layout` 内，与 `.document-body` 并列。
- 大纲顶部与正文阅读内容区域对齐，而不是与页面最顶部形成单独栏目。
- 大纲没有独立标题栏、卡片边框或独立背景。
- “大纲”标题使用 Lucide 列表图标。
- 目录项保持低对比度；当前项更深并带轻微蓝色强调。
- 文档工具栏属于共同区域，横跨正文和大纲。
- 大纲使用独立纵向滚动，但滚动条保持低对比度。

## 文档标题标签

标题下方的“项目”和“添加标签”改为独立的背景胶囊：

- 使用极浅灰或极浅蓝背景。
- 上方圆角较小，底部圆角更明显，形成参考图中的底部圆角矩形。
- “项目”包含 Lucide 标签图标。
- “添加标签”使用相同高度与内边距。
- 两个标签之间保持较小间距，不再使用裸文字布局。

## 分类图标

- 八股、学习小记、面经、项目、算法题全部使用蓝色 Lucide 图标。
- 图标容器不再使用不同的 cyan、indigo、teal、green 色值。
- 图标尺寸、线宽和基线统一。
- 分类数量继续使用中性灰色，避免抢夺图标视觉层级。

## 响应式规则

- `1920×1080`：所有栏目默认展开。
- `1440×900`：所有栏目仍可展开和手动折叠。
- `1280×720`：大纲按已有响应式规则自动隐藏，正文使用释放出的空间。
- 自动隐藏与手动折叠分离：重新回到宽屏后，大纲恢复到用户在当前页面中的手动状态。
- 当左侧导航或笔记列表折叠时，正文自动获得释放的宽度。

## 验收标准

1. 左侧导航、笔记列表和大纲均能独立展开与折叠。
2. 多个栏目可以同时折叠，正文布局不会重叠或出现横向溢出。
3. 所有操作与内容图标均来自本地 Lucide Sprite。
4. 页面不存在 Unicode、Emoji、自绘操作图标或 CSS 模拟图标。
5. 分类图标全部使用统一蓝色。
6. 激活笔记拥有参考图式蓝色竖线、留白、标题、摘要和标签层级。
7. 文档顶部工具栏跨越正文与大纲。
8. 大纲属于文档阅读区域，不表现为独立卡片或独立顶栏。
9. 大纲能够折叠，并在 `1280px` 及以下自动隐藏。
10. 文档标题下的“项目”和“添加标签”均有底部圆角矩形背景。
11. 折叠按钮具有正确的 `aria-expanded` 和动态说明。
12. 除栏目折叠外，页面不新增其他实际功能。

## 与上一版规格的关系

本规格是 `2026-08-11-coolnote-static-ui-design.md` 的增量优化，并覆盖其中“页面不包含 JavaScript”的要求。新的准确约束为：只允许使用原生 JavaScript 实现栏目折叠，不允许实现任何业务逻辑。
