# CoolNote 设计规范

版本：1.4 · 2026-08-14

## 1. 规范关系

- 产品 UI/UX 以 `product-prototype-demo.html` 为视觉与交互真源。
- 组件行为与复用边界遵循 `component-system.md`。
- 本文件规定所有页面必须遵守的通用设计底线。

## 2. 图标

- 不使用任何 Unicode 字符或 Emoji 充当图标。
- 图标只能来自 `assets/lucide-icons.svg` 或后续确定的同一图标库。
- 缺少图标时先补充图标库，再通过 `<svg><use></use></svg>` 使用。
- 图标按钮必须设置 `aria-label`，并在需要时显示 Tooltip。
- 同一动作在导航、菜单、批量栏和 Toast 中使用相同图标。
- 图标一般与相邻文本字号相当；菜单图标可比文字大 1–2px，但必须保持基线和视觉中心对齐。
- 删除、关闭等辅助图标可比相邻文本小 1–2px，但必须保持清晰可辨。
- 文字字符只用于文字内容，不得用 `＋`、`×`、`…`、`✓`、箭头或其他符号模拟控件图标。

## 3. 控件

- 应用内菜单、选择器、输入和确认不得使用 `prompt`、`confirm` 或裸 `select`。
- 高频操作就近显示；低频操作进入 Menu、Popover 或 Dialog。
- Hover、Selected、Focus、Disabled、Loading 和 Danger 状态必须明确。

### 3.1 Tooltip

- 所有仅图标按钮必须提供 `aria-label`，并由全局自绘 Tooltip 呈现该名称；禁止依赖操作系统或浏览器原生 `title` 气泡形成不一致样式。
- Tooltip 使用深灰色高对比背景、白色文字、7px 圆角、6px × 9px 内边距、12px 字号和轻量阴影；浅色与暗色主题保持同一视觉语义。
- 鼠标悬停延迟 360ms 出现，键盘聚焦立即出现；离开、失焦或按下操作后及时消失。
- Tooltip 必须采用锚点定位，默认位于触发按钮上方居中并保持 8px 间距；空间不足时翻转到下方，并始终限制在视口 8px 安全边距内。
- Tooltip 不接收指针事件，不遮断按钮操作；动画仅使用 120ms 的透明度与 2px 位移，并遵守 `prefers-reduced-motion`。
- 文案应直接描述动作，通常不超过 12 个汉字；存在快捷键时可写为“动作 · 快捷键”。

### 3.2 下拉菜单与上下文菜单

- 所有动作型下拉菜单以笔记条目“更多”菜单为唯一几何基准，不允许页面自行定义紧凑版、宽松版或顶部栏专用尺寸。
- 菜单宽度为 224px，最大宽度为 `视口宽度 - 16px`；外层内边距 6px、圆角 10px、1px 中性边框，使用统一 Popover 阴影。
- 标准菜单项最小高度 35px、水平内边距 9px、图标与文字间距 9px、圆角 6px；文字和主语义图标一律左对齐。
- 仅尾部箭头、快捷键或状态说明允许使用 `margin-left:auto` 靠右；不得因图标恰好是最后一个子元素而把整项推向右侧。
- 带副说明的新建菜单允许将单项最小高度扩展为 44px、垂直内边距 5px；菜单宽度、外层内边距、圆角、水平内边距和对齐规则不变。
- 分隔线高度 1px、四周间距 5px；危险操作保持相同行高和对齐，仅使用 Danger 语义色区分。
- 菜单默认与触发按钮保持 6px 锚点间距；支持 Light Dismiss、`Esc`、视口避让与上下翻转，滚动或缩放时持续跟随触发锚点。
- 菜单进入动效统一为 180ms 的透明度与 5px 位移；必须遵守 `prefers-reduced-motion`。

## 4. 布局与反馈

- 操作入口必须靠近作用对象，不跨区域放置。
- Hover 与 Selected 的点击区域和高亮范围保持一致。
- 列表、分类树的名称、数量和操作列必须稳定对齐。
- 可撤销操作使用 Toast；阻断操作使用 Dialog。
- 动效只解释状态变化，并支持 `prefers-reduced-motion`。
- 所有内容列表侧栏标题栏复用同一基准：标题为 17px、700 字重、深色文字；数量为 13px、500 字重、灰色文字，与标题保持 9px 间距并沿同一基线对齐。该规则适用于“收藏”“置顶”“归档”“回收站”“小记”等内容列表或资源模块；“分类”等分组标签不属于该标题层级。
- 侧边导航项中的数量使用同样的 13px、500 字重和灰色，但固定在导航项右侧的统一对齐线上并垂直居中。选中态只改变标题和图标的语义色，不改变数量的字号、颜色和位置。

### 4.1 滚动条

- 所有可滚动区域使用同一套全局滚动条，不允许业务模块自行设置颜色、宽度或轨道长度。
- 滚动条槽宽和槽高为 10px，滑块通过 2px 透明边框保持约 6px 的可见粗细；圆角必须为胶囊形。
- 纵向轨道上下、横向轨道左右各保留 24px 空白，使滚动条视觉长度短于内容容器，避免贴满面板边缘。
- 滑块最小长度为 28px；浅色主题默认使用 `#E3E7EB`，Hover 使用 `#D3D9DF`，保持低对比、淡化且仍可辨识。
- 暗色主题使用 `rgba(148,163,184,.24)`，Hover 提升至 `.38`；轨道始终透明，不绘制额外边框。
- 滚动条不得覆盖内容，局部列表优先配合 `scrollbar-gutter:stable`，避免出现时引发布局抖动。

## 5. 产品语义色

- 普通笔记工作区使用蓝色 Accent Token，不得被“小记”的主题色污染。
- “小记”界面统一使用独立紫色 Token，覆盖 `accent`、`accent-hover`、`accent-soft`、`accent-line`、`focus-ring`、`tag-bg` 和 `tag-text`。
- “小记”的导航选中、资源树 Hover/Selected、按钮 Hover、输入 Focus、Popover 选中和其他强调状态必须引用紫色 Token，不得直接引用普通笔记的蓝色值。
- 紫色 Token 仅在“小记”工作区作用域内覆盖；离开“小记”后必须恢复普通笔记的蓝色 Token。
- 删除、错误和危险操作继续使用 Danger 红色，不受“小记”紫色 Token 覆盖。
- 收藏视图使用黄色语义色：选中态文字与图标使用黄色，背景使用浅黄色，不得使用普通笔记的蓝色选中背景。

## 6. 验收

- 扫描页面不得发现 Emoji 或 Unicode 图标替代物。
- 图标引用必须能在统一图标库中解析。
- 鼠标与键盘均可完成主要流程。
- 浅色、深色和减少动画模式下保持一致。
- 分别检查普通笔记与“小记”的计算样式，确认蓝色和紫色 Token 不发生跨工作区泄漏。
