统一使用 Ionicons Outline

79 个已注册图标逐项对照。左侧是当前图标，右侧是候选；图形取自 ionicons@8.1.0 官方 SVG，保留原始线条。

字体：英文 SF Pro · 中文 PingFang SC。设置入口继续位于右上角。Ionicons 官方图标库 ↗

需要关注的近似替代：有序列表没有数字序号的直接对应图标；表格与双列布局共用 grid-outline；新建文件、新建文件夹沿用 document-outline、folder-outline，由按钮标题表达新建；文本对齐使用 menu-outline 作为近似图形；引用使用 chatbox-ellipses-outline；侧栏按钮用方向箭头表达展开与收起。可在确认前单独调整。
