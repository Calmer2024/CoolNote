# CoolNote 产品原型

版本：1.0 · 2026-08-12

## 1. 文档定位

`product-prototype-demo.html` 是 CoolNote 桌面端 UI/UX 的原型真源。本文件只解释原型的结构、状态和复现规则，不另行定义一套视觉。

Agent 开发正式产品时必须优先复现 HTML 原型，包括布局、层级、间距、显隐逻辑、浮层位置、状态反馈和动效。业务代码、数据结构与技术实现不受原型限制。

## 2. 原型边界

- 完整呈现产品工作区及主要 UI 状态。
- 交互只用于展示状态变化，不连接数据库、文件系统或真实上传。
- 示例文字和数据不是产品默认数据。
- HTML 中未出现的异常、空状态应沿用组件系统，不得回退到浏览器原生控件。

## 3. 工作区结构

| 区域       | 固定职责                               |
| ---------- | -------------------------------------- |
| 全局顶栏   | 搜索、主题                             |
| 资料库侧栏 | 系统视图、分类树、数量                 |
| 笔记列表   | 标题、筛选排序、单选、多选、快捷操作   |
| 文档顶栏   | 面包屑、保存状态、分享、文档菜单       |
| 正文编辑区 | 标题、标签、块内容、选区格式、内容插入 |
| 大纲       | 当前文档章节导航与折叠                 |
| 小记资源树 | 文件夹、小记文件、展开折叠与原地新建   |
| 小记正文   | 封面、衬线 Markdown 阅读与轻量编辑      |

各区域只承载自己的操作。笔记批量操作不得进入正文区域，文本格式操作不得进入全局顶栏。

## 4. 核心交互

| 触发                          | 原型响应                                |
| ----------------------------- | --------------------------------------- |
| 选中文字                      | 选区附近显示 `SelectionToolbar`         |
| 空块输入 `/` 或点击块左侧 `+` | 光标附近显示 `SlashMenu`                |
| Hover 正文块                  | 显示添加按钮和 `BlockHandle`            |
| Hover 笔记                    | 显示复选框、收藏和更多按钮              |
| 右键笔记                      | 指针处显示 `NoteContextMenu`            |
| 勾选笔记                      | 列表标题栏原位切换为 `SelectionBar`     |
| 点击列表排序图标              | 固定按更新时间切换升序/降序             |
| Hover 分类                    | 显示新建与删除图标                      |
| 点击分类新建                  | 选择新建笔记、新建分类或导入笔记        |
| 双击分类图标/名称             | 选择图标／进入原地重命名                |
| Hover 分类标题并点击添加      | 列表末尾原地新增分类，自动打开图标选择器 |
| 点击“小记”                   | 笔记列表切换为文件资源树，正文切换为小记主题 |
| 点击小记文件夹                | 展开或折叠子节点                         |
| 新建小记文件/文件夹           | 资源树中原地输入；Enter 或失焦确认        |
| 点击小记封面                  | 选择内置封面或调用系统文件上传            |
| 折叠小记导航                 | 资源树收起，正文获得完整可用宽度           |
| 删除、归档、移动              | Toast 反馈；可撤销操作提供撤销          |
| 需要确认或输入                | 使用 CoolNote Dialog/Popover            |
| 编辑正文                      | 显示“保存中 → 已保存”；失败状态持续可见 |

## 5. 显隐与层级

- 默认写作状态不显示固定格式栏、块工具和批量栏。
- 笔记置顶、收藏标记位于卡片右下角，Hover 操作位于右上角。
- 分类名称、数量和操作使用固定列对齐；层级缩进仅作用于名称区域。
- 分类新增态不显示背景、数量和行内操作，名称输入占满图标后的剩余宽度。
- 小记使用独立资源树，文件夹与文件必须支持展开、选中和原地新建；不得退化为普通笔记列表。
- 小记正文使用 `Noto Serif Simplified Chinese / Noto Serif SC`，支持标题、粗体、斜体、分隔线、图片、表格、高亮块等 Markdown 呈现。
- 同时只保留一个主浮层；新浮层打开时关闭旧浮层。
- 层级：内容 < 固定区域 < Menu/Popover < Toast < Dialog。
- `Esc` 关闭当前最高层；关闭后焦点返回触发对象。
- 浮层应跟随锚点并避让窗口边缘。

## 6. 视觉与动效

- 品牌色、字号、间距、圆角、阴影和各区域尺寸以 HTML 原型实际样式为准。
- Hover/按压：100–140ms；菜单：160–200ms；布局变化：200–240ms；Dialog：180–220ms。
- 动画只解释出现、消失、选择和位置变化，不使用弹跳或循环装饰动画。
- 必须支持深色模式与 `prefers-reduced-motion`。

## 7. 复现约束

- 禁止固定富文本工具栏。
- 禁止永久裸露笔记全部操作。
- 禁止 `window.prompt`、`window.confirm` 和未设计的裸 `select`。
- 图标使用统一线性图标，不使用 Emoji 代替产品图标。
- 所有页面同时遵守 `design-guidelines.md`，不得以 Unicode 字符模拟图标。
- `/` 菜单支持 `↑`、`↓` 选择项目，`Enter` 确认。
- 正式页面与原型发生视觉冲突时，以最新产品原型为准；组件实现同时遵守 `component-system.md`。

## 8. Agent 验收顺序

1. 对照原型复现静态布局和视觉。
2. 复现 Hover、选中、菜单、Dialog、Toast 与多选状态。
3. 接入真实数据和业务命令，但不得改变原型行为。
4. 在 1440×900 和最小 1024px 宽度进行截图对照。
5. 未达到主要区域、状态与动效一致时，不视为 UI/UX 完成。
