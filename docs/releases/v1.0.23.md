# CoolNote v1.0.23

- 内置原生 Rust MCP Server，无需安装 Node.js。支持笔记、任务、小记的独立读写权限、Markdown 写入、版本冲突保护与请求幂等；连接凭证由本机自动管理。
- 设置改为独立页面，入口位于右上角最右侧。主题、界面字体及 MCP 配置更改后自动应用，支持检测和搜索 Windows 本地字体。
- 统一使用 Hugeicons Stroke Rounded 图标；默认界面字体采用 SF Pro / PingFang SC，小记与社交媒体分享模板继续使用各自独立字体。
- 为侧栏、折叠内容和画廊切换增加过渡效果，支持减少动态效果偏好；画廊快速切换会丢弃过期加载响应。
- 笔记右上角提供纯图标“复制全文”；恢复 Markdown 选区复制、剪切与格式化粘贴。
- 选中文本工具条统一为 32×32，表格内和跨表格选区不再触发工具条。
- 修复图片缩放提交后高度塌陷、回弹的问题，保留拖动排序动画；拖放辅助线改为主题浅色虚线，`/` 菜单使用常规字重。
- 精简任务侧栏顶部操作，保留“任务清单”分组旁的新建入口。

MCP 默认关闭，需在设置中主动开启。当前 MCP 仅支持本机 stdio 客户端，CoolNote 桌面应用需要保持运行；更改权限或重置凭证后请重新连接客户端。

升级会自动运行资料库迁移，不改写现有笔记正文。应用数据与笔记库保留。

发布前验证包括 134 项前端测试、Rust 测试、Clippy、原生 MCP 端到端检查和生产构建；图片缩放已通过真实浏览器连续尺寸采样验证。
