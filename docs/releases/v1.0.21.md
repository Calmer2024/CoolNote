# CoolNote v1.0.21

- 记住笔记、小记、任务和画廊上次访问的位置。
- 为笔记增加分类内置顶区，统一欢迎文档与普通笔记的置顶行为，并统一列表栏宽度和分区图标。
- 表格增加复制按钮，禁用表格内拖拽，恢复完整外边框；选中文本复制时仅复制纯文本，删空一行时清除行格式。
- 优化 Tab 切换，复用已访问页面的编辑器与滚动位置，移除整页过渡动画；隐藏页面停用快捷键和浮层，继续自动保存。
- 优化长文档快照、恢复文件写入、大列表渲染和分类查询，改进全局搜索及中文短词检索。

首次打开已有笔记库时会自动升级索引；大笔记库升级耗时与数据量有关。升级不会改写用户正文。

发布前验证：95 项前端测试、28 项 Rust 测试、类型检查、生产构建和后端性能门禁。Tab 循环测试确认编辑器复用；受后台节流影响的计时数据已单独标明，不作为原生桌面性能承诺。
